# 数据模型设计

> 已锁定决策：①到期仅模型层 ②同包同计费类型 ③平台层 + 模型层均需启用开关（模型过期 / 额度耗尽自动置否，亦可手动关）④额度来源泛化：共享包 / 模型独立额度 / 无额度 三种模式，互斥

## 1. Platform（平台）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | str | 主键 |
| name | str | 平台展示名，如 "阿里云百炼" |
| base_url | str | API 地址 |
| api_key | str(加密) | 平台密钥 |
| provider | str | **LiteLLM 厂商键（平台级，权威来源）**，如 openai / dashscope / azure / bedrock。由端点形态决定：OpenAI 兼容端点（含 compatible-mode 或 /v1）填 openai；厂商原生端点才填对应键。决定旗下所有模型的 LiteLLM model 前缀。 |
| enabled | bool | **是否可用**（平台级硬开关，锁定决策③） |
| created_at / updated_at | ts | |

## 2. Model（模型）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | str | **主键，也是网关侧模型别名（路由键）**：客户端调用时传的 `model` 值、同时是 `GET /v1/models` 返回标识与 pin 锁定目标。只需**唯一且稳定**，不必等于厂商模型名（可与下方「厂商模型」解耦，用别名映射）。创建后不可改。 |
| platform_id | fk | 所属平台 |
| name | str | 展示名，如 "qwen-max" |
| enabled | bool | **模型启用开关**（默认 true；过期 / 额度耗尽自动置 false，也可手动关，锁定决策③修订） |
| provider_model | str | **网关 → 厂商的实际模型串**（如 `qwen3.7-flash-2026-07-15`）。与 `id` 解耦：id 是给客户端看的别名，本字段是给厂商看的真名。 |
| provider | str \| null | **LiteLLM 厂商键（可选覆盖）**。空则继承所属平台的 `provider`；调用时拼成 `provider/provider_model` 发给 LiteLLM。平台级才是权威来源，模型级仅在极少数需要覆盖平台时使用。**平台与模型都为空会导致 `LLM Provider NOT provided` 报错**。 |
| capabilities | list[str] | chat / code / vision / reasoning / long_context / tool_use / embedding / **json_schema / json_object / function_calling（结构化输出模式能力，由请求 response_format / tools 解析）** / ... |
| context_window | int | 上下文上限（用于长上下文分类） |
| quality_tier | enum | 旗舰 / 主流 / 轻量（质量打分用） |
| billing_type | enum | token / call（**须与所属包一致**，锁定决策②） |
| input_price_per_1k | decimal | billing_type=token 时生效 |
| output_price_per_1k | decimal | billing_type=token 时生效 |
| price_per_call | decimal | billing_type=call 时生效 |
| expired_at | datetime\|null | **到期日期（仅模型层**，锁定决策①） |
| resource_package_id | fk\|null | 所属共享额度包（与 `quota_capacity` 互斥，锁定决策④） |
| quota_capacity | float\|null | **模型独立额度总量**（无共享包时生效；与 `resource_package_id` 互斥） |
| quota_used | float | 模型独立额度已用量（单调递增） |
| created_at / updated_at | ts | |

> 说明：价格挂在模型上（不同模型单价不同），额度包只管"资源量"。

## 2.1 额度来源（quota_source，锁定决策④）

每个模型的额度来源只能是以下三种之一，且互斥：

| 模式 | 判定 | 额度载体 | 耗尽影响 |
|---|---|---|---|
| **package（共享包）** | `resource_package_id` 非空 | ResourcePackage | 级联禁用该包下**全部**模型 |
| **self（独立额度）** | `quota_capacity` 非空 | 模型自身 `quota_capacity/quota_used` | 仅停用**自己** |
| **none（无额度）** | 两者皆空（如 escape 兜底） | 无 | 不扣减、不限量、永远可路由 |

- `effective_billing_type`：共享包取包的 `unit`，独立额度取模型自身 `billing_type`。
- 共享包模型的 `billing_type` 必须与包的 `unit` 一致（同包同计费类型）。
- 自动启停：`sync_model_states` 对"共享包耗尽"与"独立额度耗尽"两类分别处理。

## 3. ResourcePackage（额度包 / 资源包）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | str | 主键 |
| name | str | 包名，如 "阿里云赠送2000万token包" |
| platform_id | fk | 采购所属平台 |
| billing_type | enum | token / call（同包所有模型一致） |
| capacity | int | 总资源量（token 数 或 次数） |
| used | int | 已用量（单调递增） |
| created_at / updated_at | ts | |

- `balance = capacity - used`。
- 一个包可挂多个模型（共享额度）；**包不单独设到期**（到期挂在模型层，锁定决策①）。
- 同包模型 `billing_type` 必须一致（锁定决策②）。

## 4. 关系

```
Platform  1 ──*  Model  *──1  ResourcePackage
```

Model 通过 `resource_package_id` 引用包；包记录共享余额。

## 5. 示例（YAML 种子）

```yaml
platforms:
  - id: ali
    name: 阿里云百炼
    base_url: https://dashscope.aliyuncs.com/compatible-mode/v1
    api_key: ${ALI_KEY}
    protocol: openai
    enabled: true
models:
  - id: qwen-max
    platform_id: ali
    name: qwen-max
    provider_model: qwen-max
    capabilities: [chat, reasoning, tool_use]
    context_window: 32768
    quality_tier: 旗舰
    billing_type: token
    input_price_per_1k: 0.02
    output_price_per_1k: 0.06
    expired_at: 2026-12-31
    resource_package_id: ali-gift-20m
  - id: qwen-turbo
    platform_id: ali
    name: qwen-turbo
    provider_model: qwen-turbo
    capabilities: [chat]
    context_window: 8192
    quality_tier: 轻量
    billing_type: token
    input_price_per_1k: 0.004
    output_price_per_1k: 0.012
    expired_at: 2026-12-31
    resource_package_id: ali-gift-20m   # 与 qwen-max 共享同一额度包
packages:
  - id: ali-gift-20m
    name: 阿里云赠送2000万token包
    platform_id: ali
    billing_type: token
    capacity: 20000000
    used: 0
```
